# El Vado

Route: `el-vado.html`. Source: the final `el vado.rar`, with its own crop and `settings-94db4b9e.json`. The previous ZIP is not used.

Both places use `historia.ts`, the same CSS, navigation and language controls. `scene.ts` supplies the model, native rendering settings and spatial scale. The existing El Vado editorial content in `vado-story.json` is preserved.

The archive contains one SOG texture set (940,996 splats). Load `el-vado/scene/0_0/meta.json` directly with SuperSplat; this keeps every received splat and all SH data. No conversion, decimation or geometry edits.

Saved views are linked by native annotation title: `00` → general; `cruz del vado` → cruz; `palo encebado` → palo; `casa de la lira` → lira; `museo` → condamine; `panaderias` → oficios; `plazoleta del vado` → plazoleta. Positions, targets, FOVs and annotation coordinates are preserved in the original settings and narrative data. El Prohibido has no saved pose in this archive and remains pending instead of receiving an invented camera.

AR route: `ar-cero.html?scene=el-vado`. Camera authoring: `recorrido.html?scene=el-vado&editar`.
